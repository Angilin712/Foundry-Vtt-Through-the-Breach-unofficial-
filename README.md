# Сквозь Пролом / Through the Breach — неофициальная система Foundry VTT

Тестовая версия **0.3.0** для **Foundry VTT 14+**. Минимум 14, верхнего ограничения установки нет; будущие поколения требуют отдельной проверки. Локальная проверка выполняется на **14.365**; целевая сборка — **14.368**. Русский интерфейс, листы Сужденного и персонажа мастера, общая Колода Судьбы и личные руки.

## Установка

В Foundry откройте **Игровые системы → Установить систему** и вставьте в поле **Manifest URL**:

```text
https://raw.githubusercontent.com/Angilin712/Foundry-Vtt-Through-the-Breach-unofficial-/main/through-the-breach/system.json
```

После установки создайте **новый тестовый мир** с системой «Сквозь Пролом — Through the Breach».

- [Скачать ZIP версии 0.3.0](https://raw.githubusercontent.com/Angilin712/Foundry-Vtt-Through-the-Breach-unofficial-/main/dist/through-the-breach-0.3.0.zip)
- [Подробная инструкция и первый запуск](through-the-breach/README.ru.md)
- [История изменений](CHANGELOG.md)

## Основные возможности

- 8 аспектов, 56 навыков, производные показатели, ресурсы и заметки персонажа.
- Общая колода из 54 карт и отдельная Смешанная колода из 13 карт для каждого Сужденного.
- Личные руки с доступом для владельца персонажа и мастера.
- Карточные проверки, модификаторы, джокеры и Обман судьбы.
- Панель мастера: раздача, перетасовки, конец сцены и отмена незавершённых проверок.
- Инициатива и флипы урона. В обычных проверках персонажей мастера используется ранг.

Добавлены оружие, атаки против защиты цели, точность, броня, применение и отмена урона, определение критической раны и проверка сознания. Таланты, триггеры, дистанция, боезапас и особые последствия состояний пока разрешаются вручную. Для карточных действий требуется подключённый мастер. Babele не является зависимостью.

## Состояние проверки

61 автоматическая проверка проходит. Манифест, доступность системы для создания мира и модели данных проверены реальными классами локального Foundry 14.365; операции обмена картами — на тестовом стенде. Шаблоны листов проверены визуально в браузере. Новые правила ходов версии 0.3.0 требуют живой проверки после перезапуска.

**Полный запуск мира с мастером и игроками на 14.368 ещё требует проверки.** Поле `verified` указывает 14.365: отсутствие этого поля блокирует выбор системы в Foundry 14. Существующие миры старой версии 0.0.2 автоматически не мигрируются.

В живом тестовом мире 14.365 подтверждены создание и запуск мира, работа всех вкладок листа, сохранение характеристик и навыков, раздача и добор, Обман судьбы, модификаторы, чёрный джокер, восстановление открытой проверки после обновления страницы, отмена проверки мастером, ранг и флип урона персонажа мастера, обновление руки после сцены. Пользователь подтвердил проверки отдельных подключений, прав доступа и устойчивости. Инициатива обоих типов в трекере, оружие, броня, применение/отмена урона и критической записи, сохранение после перезагрузки и независимый урон токену ПМ проверены в живом мире 14.365. Новые боевые действия ещё нужно пройти с игроками; Babele отдельно не проверен.

Предыдущая реализация для Foundry 13 сохранена в истории и [ветке archive/foundry13-v0.0.2](https://github.com/Angilin712/Foundry-Vtt-Through-the-Breach-unofficial-/tree/archive/foundry13-v0.0.2).
